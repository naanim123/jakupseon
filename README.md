## 데이터와 사용 조건

유료 앱은 내려받은 HTML 파일을 브라우저에서 여는 방식입니다. 견적·고객 정보는 앱 서버로 전송되지 않고 사용자의 브라우저 저장 공간에 남습니다. 브라우저 데이터 삭제나 기기 고장으로 기록이 사라질 수 있으니 JSON 백업을 별도로 보관하세요.

클라우드 동기화, 자동 업데이트, 지속적인 유지보수·지원은 포함되지 않습니다. 빠른 시작 PDF의 구매자 정보 표시는 무단 공유를 억제하기 위한 식별 표시이며, 파일 복사를 완전히 차단하는 DRM은 아닙니다. 세금·법률 자문이나 계약 효력 검토를 제공하지 않으므로 실제 금액과 거래 조건은 직접 확인해야 합니다.
